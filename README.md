# alquiler-vehiculos
Proyecto A6 de MES configurado para VS Code

## Requisitos Previos

Para ejecutar este proyecto, necesitarás:

1.  Tener **Java** instalado.
2.  Tener la extensión **Extension Pack for Java** para VS Code instalada.
3.  Duplicar la carpeta `.vscode.example` y renombrar la copia a `.vscode`.
